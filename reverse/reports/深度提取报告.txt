一、Rust WebSocket 协议：已从序列化与解析函数确认
URI 模板：ws://{运行时地址}:18889。
两个构造点的格式片段均通过 ELF 节映射和 R_AARCH64_RELATIVE 重定位恢复，精确为 ws://、一个运行时字符串、:18889。模板本身没有附加路径或查询参数；运行时服务器地址未恢复，也未访问。

外层 JSON 的六个字段：
  types        有符号 32 位整数
  data_content 字符串，可包含第二层 JSON
  from         字符串
  to           字符串
  fp           字符串
  qos          布尔值
发送总是输出 types/qos，其余四个字符串为空时省略。接收缺少字段时按 types=0、qos=false、字符串为空处理。
上述说明来自原生序列化、解析控制流，已分开保存发送/接收 JSON Schema，不能把字符串 data_content 直接替换为 JSON 对象。

已确认的外层类型分支：
  2   接收业务消息
  4   QoS ACK，含发送构造器及接收移除等待队列逻辑
  6   发送登录
  50  接收登录响应
  51  接收 Keep Alive 心跳响应，更新保存的时间
  52  服务端错误响应分支，日志 on_server_response_error
  54  接收被踢下线指令并调用断开处理
只列出了已审查分支，不是完整协议枚举。52 分支未确认向界面转发错误内容。

登录响应 types=50 的 data_content 内层要求：
  code: i32；user_id: String；data: String。
三个命名字段都有缺失错误路径；code=0 进入成功分支，非零进入失败分支。
登录请求的 data_content 具体内容暂未恢复；已确认发送器把收到的字符串装入 types=6 的 Protocol。

业务消息 types=2 的 data_content 解为 JSON，读取独立的 msg_type。
msg_type 为 101、102、113、114、115、116、117 时，原 data_content 字符串进入 Rust -> Flutter 事件转发函数。
其它值没有走这个已检查处理器的同一转发路径；各值的业务名称与剩余 payload 字段仍未确认，不能直接冠以“图片”“设备状态”等名称。

ACK 构造器：types=4，qos=false；data_content=收到的 fp；交换 from/to；生成新的 UUID fp。
init_ws、ws_login 的 FRB wire 参数解码器各读取一个 UTF-8 String，前面是 4 字节小端 i32 长度。它属于本地 FFI 参数格式。
该业务事件的字节顺序为：u8(0) + 4 字节小端事件整数(4) + 第一字符串的 4 字节长度与 UTF-8 + 第二字符串的 4 字节长度与 UTF-8。
第一字符串为空，第二字符串保留原 data_content；总长为 13 + data_content 的 UTF-8 字节数。外层以 Dart_CObject 外部 Uint8 数据发送到 Dart port。
转发结构的整数值 4 是事件字段，不应直接理解为 enum variant。独立指令复核见 analysis/deep_rust/flutter_event_encoding.json；原始字段名未绑定。

三、Go RSA 桥接库：恢复通用能力和二进制请求结构
librsa_bridge.so 保留 Go 1.21.0 pclntab 和构建信息。本轮恢复 4,221 个函数条目，包含 191 个 jerson/rsa-mobile 相关函数。
分发器恢复 34 个操作，均以 ARM64 比较常量/完整字面量独立核对操作名称。
请求使用 FlatBuffers，构建信息中的依赖版本为 v2.0.6。恢复 28 张请求表、76 个字段的名称、顺序、vtable 偏移和访问器地址，另恢复 11 张响应/值表及 4 个 Go 返回结构的 RTTI。
能力包括 RSA OAEP、PKCS1v15 加解密，PSS/PKCS1v15 签名验证，字符串/字节版本，生成密钥、密钥信息、哈希/Base64、JWK/PKCS/PKIX 转换。
重建 .fbs 是分析产物，命名空间与源格式不是原始源码；部分整数的 enum 别名、signedness 及 String/byte-vector 区别保留推断说明。
枚举初始化指令还确认 Hash 的 MD5/SHA1/SHA224/SHA256/SHA384/SHA512、Cipher 的 DES/D3DES/AES128/AES192/AES256 与 SaltLength 的 AUTO/EQUALS_HASH 编号，见 enum_values.json。
RSABridgeCall C ABI 接受 method 指针、request 指针与 int32 长度，返回 malloc(24) 的结构指针（+0 数据指针、+8 长度、+16 原生错误指针）。FlatBuffers 响应的 slot 1 还可承载运算错误；调用方释放策略尚未恢复。
这些是随包库能力。尚未证明 Dart 登录、设备控制或本地私钥实际调用其中某个操作。不能把可用 OAEP/PSS 能力直接当作业务所选填充方式。
fast_rsa Java 通道处理器返回 notImplemented 形式的空回复。三个架构的 Dart AOT 多编码字面量检索未命中 RSA 专用导出/库名/操作名，不能因此排除动态构造或 FFI 调用；详细证据见 actual_invocation_evidence.json。
主要产物：analysis/deep_rsa/go_functions.tsv、operation_request_response.tsv、operations.json、request_models.json、request_models_reconstructed.fbs、response_models_reconstructed.fbs、dispatch_literal_checks.json、go_response_structs.json、native_bridge_contract.json、深入RSA分析说明.txt。
